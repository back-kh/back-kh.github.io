Dataset Summary

PALM-LAY is a unified cross-regional layout-analysis dataset for historical palm leaf manuscripts. It addresses a key limitation in palm leaf document analysis: annotated resources are often scarce, fragmented by region, and difficult to compare across scripts.

The dataset contains more than 566 manuscript pages and over 6,000 annotated regions spanning Tamil, Kambaramayanam, Jathakam, Khmer, Sundanese, and Balinese. These scripts have distinct linguistic and visual properties, but many share long, narrow manuscript pages, text-line structures, degradation patterns, and archival artifacts.

PALM-LAY supports layout-aware experiments before OCR and full text recognition. It is designed to help researchers evaluate cross-script generalization, region detection, manuscript structure understanding, and preservation-oriented document processing.

Unified Layout Schema

Each page is annotated with seven region categories. The schema captures both traditional manuscript content and additional archival or physical features that can affect document analysis models.

MainRegion

Primary manuscript body or palm leaf area.

TextLineRegion

Individual text lines for layout parsing.

ParagraphRegion

Grouped text blocks or paragraph-like structures.

SymbolicMark

Markers, separators, and symbolic manuscript signs.

PhysicalDamage

Holes, cracks, stains, missing parts, and degradation.

Illustration

Decorative or semantic non-textual drawings.

Other

Modern archival additions or regions outside the core labels.

Dataset Workflow

1

Curate cross-regional sources

Collect pages from publicly available palm leaf manuscript collections covering South and Southeast Asian scripts.

2

Apply one annotation schema

Use a consistent set of region labels so models can be trained and compared across different scripts.

3

Verify layout regions

Review main areas, text lines, damage, symbols, illustrations, and other regions for quality.

4

Benchmark and release

Evaluate object detection models and provide dataset documentation for reproducible research.

Benchmark Tasks

Region detection

Detect manuscript regions using object detection models and evaluate category-level performance.

Cross-script transfer

Train and test across different scripts to measure generalization under domain shift.

Preservation analysis

Localize physical damage and structural regions that influence restoration and digitization workflows.
