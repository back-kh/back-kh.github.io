PALM-GLOBAL: Cross Domains Palm Leaf Manuscript Analysis

Bridging South Asia and Southeast Asia for unified palm leaf manuscript analysis, preservation, and dataset-centered benchmarking.

Explore Tasks PALM-LAY Dataset

Project Overview

PALM-GLOBAL extends the PALM-SEA project from a Southeast Asian focus toward a unified cross-domain study of palm leaf manuscripts across South Asia and Southeast Asia. The project studies shared manuscript structures while respecting the diversity of scripts, layouts, physical conditions, and cultural contexts.

The goal is to develop practical document-analysis resources for historical palm leaf collections: common annotation schemas, interoperable datasets, baseline models, and task-specific pages for dataset creation, enhancement, layout analysis, recognition, and preservation workflows.

The first public dataset task is PALM-LAY, a multi-script cross-regional layout-analysis dataset introduced in ICDAR 2025 Workshops proceedings. It unifies manuscript pages and region labels for cross-script experiments and future downstream tasks.

Core Goal

Create a bridge between regional palm leaf manuscript datasets so models can learn transferable layout, enhancement, and recognition knowledge across low-resource scripts.

Script and Region Coverage

Khmer

Balinese

Tamil

South Asian manuscript pages included for cross-regional layout and preservation studies.

A manuscript tradition represented in PALM-LAY for evaluating transfer across related page structures.

Jathakam

A cross-domain component that helps test model robustness beyond one script family or region.

Dataset Portal

PALM-LAY: A Multi-script Cross-Regional Dataset for Layout Analysis of Palm Leaf Manuscripts

PALM-LAY introduces a unified layout annotation schema for palm leaf manuscript pages from Tamil, Kambaramayanam, Jathakam, Khmer, Sundanese, and Balinese sources. It is the first task page in PALM-GLOBAL and will be used as the anchor for dataset release notes, documentation, and benchmark updates.
